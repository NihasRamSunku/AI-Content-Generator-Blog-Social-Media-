💻 AI Code Explainer Tool

An AI-powered web application that explains programming code in simple language using Groq + Streamlit.

Built for students, beginners, and developers who want to understand code faster.

---

🚀 Features

- Explain code step-by-step
- Beginner Mode & Advanced Mode
- Multi-language support
- Bug detection suggestions
- Clean Streamlit UI
- Powered by Groq LLMs

---

🛠 Tech Stack

- Python
- Streamlit
- Groq API
- LLaMA 3.1 Models

⚙️ Installation

1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/ai-code-explainer.git
cd ai-code-explainer
```

---

2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

3️⃣ Set API Key

Windows

```bash
setx GROQ_API_KEY "your_api_key"
```

Mac/Linux

```bash
export GROQ_API_KEY="your_api_key"
```

---

4️⃣ Run Application

```bash
streamlit run app.py
```
